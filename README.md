# Anwar al-Raml (رمل انوار)

An app built from the lithograph "Anwar al-Raml" (Newal Kishore Press).
Every rule carries its printed page number, and the scan of the book is kept here so you can verify it yourself.

برنامهٔ رمل ساخته‌شده از کتاب «انوار الرمل».
پژوهشگر: دکتر علی‌اصغر کرم قشقایی.
تصحیح و برنامه‌نویسی با کمک Claude.
