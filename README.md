# Anwar al-Raml (رمل انوار)

An app built from the lithograph "Anwar al-Raml" (Newal Kishore Press).
Every rule carries its printed page number, and the scan of the book is kept here so you can verify it yourself.

## The scan / اسکن کتاب

The scan is a multi-part archive: 1.part1.rar to 1.part6.rar.
Download ALL six parts into the same folder, then open 1.part1.rar with any RAR tool (e.g. RAR for Android, WinRAR, 7-Zip). The book will be extracted automatically.

اسکن کتاب یک آرشیو چندبخشی است: ۶ فایل از 1.part1.rar تا 1.part6.rar.
هر شش فایل را در یک پوشه دانلود کنید و سپس فقط 1.part1.rar را با برنامهٔ RAR (مثلاً RAR برای اندروید، WinRAR یا 7-Zip) باز کنید.
